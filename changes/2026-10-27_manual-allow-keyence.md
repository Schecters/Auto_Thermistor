# 2026-10-27 — โหมด Manual: รับบาร์โค้ดจาก Keyence ได้ด้วย

## ปัญหาเดิม
- โหมด Manual รับบาร์โค้ดจาก Scanner USB อย่างเดียว บาร์โค้ดจาก Keyence ถูกทิ้ง

## สิ่งที่จะแก้
- **Manual**: รับได้ทั้ง Scanner USB และ Keyence
  - ส่ง MES ทันที ไม่รอ M3031
  - M3031 จาก 0 เป็น 1 ยังเริ่มทดสอบได้เหมือนเดิม
- **Auto**: ไม่เปลี่ยน
  - รับบาร์โค้ดจาก Keyence อย่างเดียว
  - รอ M3031 = 1 ก่อนส่ง MES
- เอาเงื่อนไขเช็คโหมดออกจาก `KeyenceScanner_BarcodeReceived` ให้ส่งบาร์โค้ดเข้า Flow ทุกโหมด
