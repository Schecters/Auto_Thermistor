# 2026-10-15 — ป้าย PASS/FAIL ตัดคำ + แก้จุดเสี่ยงจากการตรวจโค้ด

**ไฟล์ที่จะแก้:** `Themister_Real/Form2.cs`, `Themister_Real/Form1.cs`

## ปัญหาที่ผู้ใช้เจอ
ป้ายผลทดสอบ (`lbPassFail`) แสดงแค่ 3 ตัวอักษร เช่น "REA" แทน "READY"

**สาเหตุ:** Designer ตั้งป้ายเป็น AutoSize ฟอนต์ 70pt ขนาด 297×107 (พอดีคำว่า PASS)
แต่ธีม UI รอบก่อนปิด AutoSize และเปลี่ยนเป็น Segoe UI ตัวหนา → ตัวหนังสือกว้างกว่ากล่อง จึงถูกตัด

## สิ่งที่จะทำ
1. **ป้าย PASS/FAIL/READY/TEST** — คำนวณขนาดฟอนต์ให้พอดีกล่องอัตโนมัติทุกครั้งที่ข้อความหรือขนาดหน้าต่างเปลี่ยน
   และเปลี่ยนสี "TEST" เป็นโทนเดียวกับธีม
2. **Keyence ส่ง "ERROR"** — ให้ทำงานเหมือน scanner USB (โหมด No MES: ขึ้น FAIL และสั่ง PLC M3030 ปล่อยชิ้นงาน)
   ตอนนี้แค่ขึ้น "Scan Error" → ไลน์อาจค้างรอ PLC
3. **สร้าง JSON ด้วย JsonSerializer** แทนการต่อ string — Login (Form1) และ Update Route (Form2)
   SN หรือรหัสผ่านที่มี `"` หรือ `\` ทำให้ JSON พัง (รูปแบบข้อมูลที่ส่งไป MES เหมือนเดิม)
4. **หลังรัน Sequence ไม่ครบ** (Recipe ว่าง / กด Stop / Error) — ป้ายกลับเป็น "READY" แทนค้างที่ "TEST"
   และกด Stop แล้วแสดง "หยุดเรียบร้อย" ถูกต้อง (ตอนนี้บางครั้งขึ้น "Execution Error")
5. **Line ending ของ Form2.cs** — ทำให้เป็น CRLF ทั้งไฟล์

## ข้อเสนอ (ยังไม่ทำรอบนี้)

- `catch { }` เงียบ 14 จุด — ควร log ไว้บ้าง
- Keyence หลุดแล้ว reconnect อัตโนมัติ
