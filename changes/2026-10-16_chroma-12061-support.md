# 2026-10-16 — รองรับ Chroma 12061 (6½ Digit DMM) ผ่าน USB โดยยังใช้กับ Picotest ได้

## อาการ
เลือก Chroma 12061 ใน Dropdown แล้วกด Connect ได้ (ไฟเขียว) แต่สั่ง Multimeter วัดค่าไม่ได้

## สาเหตุที่น่าจะเป็น
1. `DetectPipes()` เลือก Endpoint ขาเข้า "ตัวสุดท้ายที่เจอ" โดยไม่ดูชนิด — Chroma เป็น USBTMC/USB488 ที่มี
   Interrupt-IN Endpoint เพิ่มมา ทำให้โปรแกรมไปอ่านคำตอบจาก Interrupt Pipe แทน Bulk-IN จึงไม่ได้ค่ากลับ
2. Pipe Timeout 1.5 วินาที สั้นไปสำหรับ DMM 6½ หลัก (NPLC 10 + Auto Range) — อ่านค่าไม่ทันแล้วถือว่าค้าง
3. `SYST:REM` เป็นคำสั่งเฉพาะ Picotest/RS-232 — Chroma (SCPI แบบ 34401) จะขึ้น Error ทุกครั้งที่ส่ง
4. ไม่ได้ส่ง USB488 `REN_CONTROL` (Remote Enable) ที่ VISA ปกติส่งให้เครื่อง USB488

## สิ่งที่จะแก้ (Form2.cs)
- `DetectPipes()` เลือกเฉพาะ **Bulk** IN/OUT ตัวแรก (Picotest ก็ใช้ Bulk อยู่แล้ว ผลเหมือนเดิม)
- ตั้ง Timeout ขาเข้าเป็น 3 วินาที, เปิด `SHORT_PACKET_TERMINATE` ขาออก, ขยาย Buffer อ่านเป็น 2048
- ตอนเชื่อมต่อส่ง USB488 `REN_CONTROL` (ถ้าเครื่องไม่รองรับจะข้ามไปเฉย ๆ) แล้วถาม `*IDN?`
- ส่ง `SYST:REM` เฉพาะเครื่องที่ไม่ใช่ Chroma (Picotest ยังได้คำสั่งเดิมทุกตัว)
- ตอนอ่านคำตอบ ตรวจ bTag และรวมข้อมูลกรณีคำตอบมาหลายก้อน
- แท็บ Connection: แสดงชื่อเครื่องจาก `*IDN?` และเพิ่มปุ่ม **Test** สั่ง `READ?` 1 ครั้งเพื่อทดสอบที่หน้างาน
