# 2026-11-03 — นับ OK / NG ต่อกะ ตามการส่ง MES

## ความต้องการ
- แสดงจำนวน OK / NG ของกะปัจจุบัน
  - กะเช้า 07:40–19:10
  - กะดึก 19:40–07:10 (ข้ามเที่ยงคืน)
- นับตามการส่ง MES

## กติกาการนับ (ตกลงกับผู้ใช้)
1. นับเฉพาะตอนที่ `routing-update` สำเร็จ (MES ตอบ HTTP 2xx)
   - PASS → OK +1, FAIL → NG +1
   - ส่งไม่สำเร็จ / FAIL แล้วกด Cancel (ไม่ส่ง) / โหมด No MES → ไม่นับ
2. ช่วงพักนับรวมกะที่เพิ่งจบ: 19:10–19:40 → กะเช้า, 07:10–07:40 → กะดึก
   เส้นแบ่งกะจึงเป็น 07:40 และ 19:40
   - 07:40–19:39 = กะเช้าของวันนั้น
   - 19:40–23:59 = กะดึกของวันนั้น
   - 00:00–07:39 = กะดึกของเมื่อวาน
3. ข้ามกะแล้วเริ่มนับ 0 ใหม่อัตโนมัติ (ตรวจทุก 30 วินาที และตอนนับ)

## สิ่งที่จะแก้ (`Form2.cs`)
1. `SendRoutingUpdateAsync(jsonPayload, isPass)` — ส่งสำเร็จ → `AddShiftCount(isPass)` (แก้ 3 จุดที่เรียก)
2. เก็บค่าใน `shift_count.cfg` (โฟลเดอร์โปรแกรม เหมือน cfg อื่น) รูปแบบ `yyyy-MM-dd|D หรือ N|OK|NG`
   - ปิด/เปิดโปรแกรมในกะเดิมยังนับต่อ
   - ถ้าเป็นกะใหม่ เริ่ม 0
3. แสดงกลางแถบหัว DELTA (วาดใน `HeaderBar_Paint`):
   `DAY SHIFT 07:40–19:10   OK 120   NG 3` (OK สีเขียว, NG สีแดง)
4. Timer 30 วินาที ตรวจการข้ามกะ
