# 2026-10-27 — โหมด Auto: รอ M3031 (แทน M30) ก่อนส่ง API แล้วสั่ง M3030

## ปัญหาเดิม
- ตอนนี้โหมด Auto รอให้ M30 = 1 ก่อนส่ง API routing-update
- หน้างานต้องการใช้ M3031 เป็นตัวบอกว่าพร้อมส่งแทน

## สิ่งที่จะแก้
1. โหมด Auto
   - ทดสอบเสร็จแล้ว ให้อ่าน **M3031** (Coil 3031) จาก PLC ทุก 100 ms จนได้ค่าเป็น 1
   - จากนั้นส่ง API routing-update
   - ส่งเสร็จแล้วเขียน **M3030 = 1** ไปที่ PLC (เหมือนเดิม)
   - ระหว่างรอ ป้ายขึ้น "Waiting M3031..." กด Stop เพื่อยกเลิกได้
2. โหมด Auto: ปิดการเริ่มทดสอบอัตโนมัติจากขอบขาขึ้นของ M3031
   - โหมด Auto ใช้ M3031 เป็นสัญญาณ "พร้อมส่ง" และเริ่มทดสอบจากการสแกน Keyence อยู่แล้ว
   - ถ้าเปิดไว้ M3031 จะไปเริ่มทดสอบซ้ำด้วยบาร์โค้ดเก่า
   - โหมด Manual ยังเริ่มทดสอบจาก M3031 ได้เหมือนเดิม
3. เลิกอ่าน M30
